🚀 Core Strengths & Advantages
Verified Features

Messages arrive instantly on the screen via STOMP/SockJS without any page reloads or polling overhead.

🛡️ Integrated Sentiment & Anti-Spam Filter

Bilingual (FR/EN) sentiment analysis flags toxic words in real time, while Redis rate-limits protect against flood attacks.

📸 1-Click Story Reply Export

Generates formatted visual response cards (html2canvas) directly ready to post on Instagram Stories and TikTok.

🔗 Zero Friction for Senders

Anyone can send an anonymous message via the user's public link without creating an account or logging in.

🏗️ Solid Fullstack Foundation

Angular 18 (Signals), Spring Boot 3 / Java 21, PostgreSQL, Redis, and installable PWA support.

⚠️ Current Limitations & Roadmap
Engineering Transparency
🤖 Lexical Matching vs Deep Transformer AI

Currently dictionary-based; does not yet parse complex sarcasm, double entendre, or nuanced internet slang (LLM roadmap).

📱 PWA / Web App vs Native App Stores

Runs as a responsive web app and installable PWA; not yet packaged as native binaries on Apple App Store or Google Play.

💳 Simulated Virtual Coin Economy

The in-app coin wallet for unlocking sender clues is currently simulated; not yet connected to live payment billing (Stripe/Apple Pay).

🔔 No Background Push Notifications

Real-time alerts work via WebSockets when the tab is open, but native background mobile push (FCM/APNs) is not yet active when closed.

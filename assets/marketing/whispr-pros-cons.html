✨ Key Advantages
4 Core Strengths
⚡ Real-Time WebSockets Experience

Messages arrive on screen instantly via STOMP/SockJS without any manual page reload or polling lag.

🛡️ Integrated Sentiment & Anti-Spam

Real-time bilingual (EN/FR) toxicity detection coupled with Redis rate-limiting prevents mass flooding and basic harassment.

📸 Frictionless Viral Social Loop

Zero account required to send. 1-click snapshot card export (html2canvas) lets users post replies directly to Instagram Stories & TikTok.

🏗️ Modern Enterprise Foundation

Clean architecture: Angular 18 Signals, Spring Boot 3 / Java 21, PostgreSQL, Redis, full i18n, and installable PWA support.

⚠️ Current Limitations & Roadmap
4 Honest Boundaries
🤖 Lexical vs Deep Contextual AI

Currently dictionary-based. Lacks deep transformer LLMs (BERT/OpenAI) to understand subtle sarcasm, slang, or encoded bullying.

📱 Web/PWA vs Native App Stores

Runs as a responsive web app and PWA; not yet distributed as a native binary on the Apple App Store or Google Play Store.

💳 Simulated Virtual Coin Economy

The in-app coin wallet for unlocking sender clues is currently simulated; not yet wired to a live payment gateway (Stripe/Apple Pay).

🌐 VPN & Proxy Clue Bypassing

Sender city and country clues rely on IP geolocation headers, which can be spoofed or masked by senders using VPNs.

# Development Guidelines & Git Workflow

## Git & Pull Request Workflow (MANDATORY)
For all code changes, strictly follow this Git branch and PR workflow:
1. **Never commit directly to `main`**: Always create a dedicated branch (e.g., `feat/...`, `fix/...`, `chore/...`, `refactor/...`).
2. **Commit changes on the branch** with clear, conventional commit messages.
3. **Push the branch and open a Pull Request (PR)** targeting the `main` branch.
4. **Branch deletion**: Only delete/close the branch once its Pull Request has been reviewed and merged into `main`.
